# Oxford-Cpp-Programming-Exercises
Selected C++ programming exercises completed during the University of Oxford C++ Programming course, demonstrating core C++ concepts including file I/O, references, OOP, dynamic memory, operator overloading, inheritance, polymorphism and templates.

## Topics Demonstrated

- File I/O
- Arrays and multidimensional arrays
- Functions and function overloading
- References
- std::vector
- Classes and encapsulation
- Constructors and destructors
- Operator overloading
- Dynamic memory allocation
- Pointers and pointer arithmetic
- Inheritance
- Virtual functions and polymorphism
- Function templates
- Generic programming

## Purpose

These exercises represent selected examples from my formal C++ study
and demonstrate progression from fundamental programming constructs
through to intermediate C++ language features.
